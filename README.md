# Nioo Food - Compte rendu de production et de ventes

Application React (Vite) pour saisir la production et les ventes de jus,
calculer le stock restant et le chiffre d'affaires, puis exporter en PDF.

## Installation
    npm install
    npm run dev

Ouvrir http://localhost:5173

## Build de production
    npm run build
    npm run preview
